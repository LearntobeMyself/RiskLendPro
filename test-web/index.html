快速说明

  1. 确保 MySQL 已执行 sql/migration_supplement.sql
  2. 启动后端：mvn spring-boot:run
  3. 用 Live Server 打开本目录，或 npx serve test-web
  4. 用户端 user.html 按场景选择预设 → 注册 → 登录 → 提交评估
  5. 管理员端 admin.html 登录后刷新列表 → 点击行看报告 → 审批
