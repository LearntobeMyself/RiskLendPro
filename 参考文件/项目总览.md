# RiskLendPro 风控评分系统 - 项目总览

***

## 一、项目概述

### 1.1 项目定位

**RiskLendPro** 是一个基于 Java + Python 的风控评分系统，采用**离线训练 + 在线评分**的分离架构，用于贷款申请的自动化风险评估。

### 1.2 核心目标

| 目标        | 说明                          |
| --------- | --------------------------- |
| **自动化决策** | 根据用户信息和外部征信数据自动评估贷款风险       |
| **数据驱动**  | 基于真实业务数据（LendingClub）训练评分规则 |
| **可解释性**  | 提供详细的评分明细和决策依据              |
| **灵活扩展**  | 支持规则动态更新，无需重启服务             |

### 1.3 技术架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        离线处理层（Python）                          │
├─────────────────────────────────────────────────────────────────────┤
│  数据准备 → 模型训练 → 规则生成 → 规则入库                             │
│  (CSV分析)   (逻辑回归)   (业务规则)   (MySQL)                        │
└───────────────────────────┬─────────────────────────────────────────┘
                            │ 写入数据库
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│                        在线服务层（Java）                            │
├─────────────────────────────────────────────────────────────────────┤
│  读取规则 → 用户特征获取 → 评分计算 → 决策输出                        │
│  (MySQL)   (外部API)     (业务规则)   (APPROVE/REVIEW/REJECT)        │
└─────────────────────────────────────────────────────────────────────┘
```

## 三、评分规则体系

### 3.1 评分维度

| 维度       | 特征                   | 评分范围       |
| -------- | -------------------- | ---------- |
| **个人信息** | 年龄、收入、工作、学历、房产、车产、婚姻 | -15 \~ +15 |
| **外部征信** | 多头借贷、征信查询、逾期次数、DTI   | -40 \~ +5  |
| **反欺诈**  | 虚拟设备、代理IP            | -20 \~ 0   |

### 3.2 核心评分规则

```json
{
  "feature_scores": {
    "age": {
      "groups": [
        {"range": [22, 25], "score": -10},
        {"range": [30, 40], "score": 8},
        {"range": [40, 50], "score": 5}
      ]
    },
    "overdue_count_12m": {
      "groups": [
        {"range": [0, 1], "score": 0},
        {"range": [1, 2], "score": -15},
        {"range": [3, 99], "score": -40}
      ]
    }
  },
  "thresholds": {
    "auto_approve": 75,
    "manual_review": 50
  }
}
```

### 3.3 决策逻辑

| 分数范围   | 决策      | 说明          |
| ------ | ------- | ----------- |
| >=75分  | APPROVE | 自动通过，生成授信额度 |
| 50-74分 | REVIEW  | 人工审核        |
| <50分   | REJECT  | 系统拒绝        |

**注意事项**：评分卡具体规则仍待优化，当前规则基于初始数据分析，后续可根据实际业务反馈和更多数据进行调整优化。

## 四、核心流程

### 4.1 Python 离线训练流程

```
1. 数据准备
   └── 将 loan.csv 复制为 data/training_data.csv

2. 数据处理
   ├── 筛选有效样本（Charged Off / Fully Paid）
   ├── 特征转换（年收入→月收入等）
   └── 标签生成（defaulted = 1/0）

3. 特征分箱
   ├── 年龄、收入、DTI 等连续特征分箱
   └── 生成类别特征用于模型训练

4. 模型训练
   └── 逻辑回归（class_weight='balanced'）

5. 规则生成
   ├── 基于数据统计生成业务规则
   ├── 计算特征相关性
   └── 生成 scoring_rules.json

6. 规则入库
   └── 写入 MySQL scoring_rules 表
```

**参考文档**：

- `README.md` - Python训练流程详细设计
- `csv数据来源和数据库表设计.md` - 数据处理步骤说明

### 4.2 Java 在线评分流程

```
1. 申请提交
   └── 检查是否有正在处理的申请（WAITING状态）

2. 黑名单检查
   └── 命中则直接拒绝

3. 特征获取
   └── 从 user_external_features 查询用户征信数据

4. 评分计算
   ├── 基础分 100 分
   ├── 个人信息评分（年龄、收入、工作等）
   ├── 外部征信评分（多头、查询、逾期、DTI）
   ├── 反欺诈检测（虚拟设备、代理IP）
   └── 分数归一化（10-90分）

5. 决策输出
   ├── APPROVE → 计算授信额度
   ├── REVIEW → 进入人工审核队列
   └── REJECT → 拒绝申请

6. 结果缓存
   └── 评分报告存入 Redis
```

## 七、关键设计要点

### 7.1 数据驱动设计

评分规则基于真实业务数据生成：

| 数据特点         | 设计应用                        |
| ------------ | --------------------------- |
| 样本不平衡(85:15) | 使用 class\_weight='balanced' |
| 特征相关性分析      | 逾期权重最高，收入次之                 |
| 真实违约分布       | 评分区间根据违约率确定                 |

**参考文档**：

- `使用csv数据说明.md` - 数据驱动设计说明

### 7.2 规则更新机制

```
Python训练 → scoring_rules.json → MySQL → Java读取
                                          │
                                          ▼
                                   动态更新评分规则
                                   无需重启服务
```

### 7.3 容错机制

| 场景     | 处理方式      |
| ------ | --------- |
| 数据库无规则 | 使用硬编码兜底规则 |
| 特征数据缺失 | 对应项评分为0   |
| 评估异常   | 自动设置为拒绝   |

**参考文档**：

- `风控流程.md` - 容错机制说明
