# 测试数据核验（收入偏差）+ 规则层人工仍算分

> 自填「15000以上」时，后台月入 = `AMT_INCOME_TOTAL / 12`。偏差 = `(15000 - 后台月入) / 后台月入`（仅当后台月入 **低于** 区间下限时计算）。
