# 综设 III 需求清单

每一条对应飞书「需求列表」中的一行。格式对齐课件示例：编号、角色、模块、用户故事、关键讨论、数据/规则、验收标准。

状态默认 **未开始**。优先级均为本学期 **必做**，除非标明提升。排期看 [综设III四阶段计划.md](./综设III四阶段计划.md)，关联任务是 `G-S1` 这种阶段行，不是旧的周编号。

图例：需求来源 **已有** / **优化** / **新增**。所属阶段：S1 中期前 / S2 三条主路径 / S3 贷中贷后获客安全 / 提升（不挡阶段完成）。
