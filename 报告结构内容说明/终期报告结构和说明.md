## 项目新增功能说明（终期版）

在中期基础上，终期版已新增并完善以下核心功能：

### 1. A卡/B卡双评分卡系统

- **A卡（贷前申请评分卡）**：用于贷款申请阶段的信用评估，基于 Home Credit 数据训练，采用 WOE 分箱 + Logistic Regression + PDO 标准化
- **B卡（贷后行为评分卡）**：用于贷后行为监控和风险预警，基于历史还款行为特征（`inst_*`、`pos_*` 等）训练
- 两张评分卡规则物理分离，分别存储在 `scoring_rules` 和 `behavior_scoring_rules` 表中

### 2. 黑名单自动同步系统

- **双通道更新**：
  - 全量更新：`clean_blacklist.py` + `load_to_mysql.py`（开发/首次部署用）
  - 增量更新：扣子平台定时工作流 + `POST /api/v1/sync/blacklist`（生产用）
- **数据来源**：浙江温州市失信被执行人公开数据（约 2497 条）
- **定时同步**：扣子 Cron 每日 02:00 抓取温州公开数据，清洗后调用 API 增量入库，自动去重 `(name, area_code, birth_year)`

### 3. 补充材料流程

- **用户端**：进入人工复核时可上传证明材料（`POST /risk/assessment/supplement/upload`）
- **管理员端**：可查看用户上传的材料（`GET /admin/supplement/file/{materialId}`）
- **风控评分展示**：管理员可查看完整的评分明细、特征贡献、黑名单匹配结果等
- **材料要求**：支持身份证正面、收入证明等类型，单文件 ≤ 5MB，支持 jpg/png/pdf

### 1.1.3 关键功能模块划分

**关键词**：双评分卡引擎、风控评估、黑名单同步、补充材料、人工审批、管理端

**中心内容**：中期模块表 + 终期增加 **「风控子系统」框图**：离线训练（A/B 卡） | 在线引擎（A 卡 + B 卡） | 黑名单同步 | 补充材料 | 人工审批 五模块关系。

**模块详细说明**：

1. **离线训练模块**（Python）：
   - A卡训练：`train_scoring_model.py` → `scoring_rules.json`
   - B卡训练：`train_b_card_model.py` → `b_scoring_rules.json`

2. **在线引擎模块**（Java）：
   - **CreditScoreEngineImpl**：A 卡贷前评分（350–950 分，阈值 788/642）

3. **黑名单同步模块**：
   - 扣子平台定时 Cron 工作流（每日 02:00）

4. **补充材料模块**：
   - 用户端：`RiskSupplementController` 上传材料（`POST /risk/assessment/supplement/upload`）

### 1.3.2 核心模块A：Python 离线训练与规则生成

#### 1.3.2.1 模块职责与接口定义
