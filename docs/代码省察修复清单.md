# RiskLendPro 代码省察修复清单

> 审查方式：基于 `self-code-review` 方法论，按 Block/Should/Nit 严重度分级。
> 覆盖：数据库表设计、实体类、业务流程、代码质量、安全、测试。
> 建议节奏：按批次小步提交，逐项验收后再进入下一批。

---

## 第 1 批：安全加固（优先）

### 修复 1 — JWT 密钥外置且服务端可配密
- **文件**：`services/common-runtime/src/main/java/org/example/risklendpro/common/security/JwtConfig.java`（L15）
- **改动**
  - 删除硬编码 `SECRET` 常量，改为 `@Value("${security.jwt.secret}") String secret` 注入（与网关同 key）。
  - 启动校验：若 secret 为 `blank` 或等于默认值 `MySecretKeyForJWT2024VeryLongAndSafe12345678`，抛异常拒绝启动（强制非本地下发）。
  - 服务端各 `application.yml` 增加 `security.jwt.secret: ${JWT_SECRET:...}` 覆盖项。
- **验收**：本地保持默认可跑；`JWT_SECRET` 设为其他值时，网关与服务端均能正常签发/校验 token。

### 修复 2 — 还款越权（IDOR）：归属校验
- **文件**：`services/loan-service/.../loan/repay/RepaymentServiceImpl.java`（L60-L104）、`RepaymentController.java`（L38-L41）
- **改动**
  - `executeRepayment` 增加参数 `Long userId`（controller 用 `SecurityUtils.getUserIdFromRequest` 传入）。
  - `plan.getUserId().equals(userId)` 校验，不符抛 403。
- **验收**：A 用户用 B 的 planId 还款被拒。

### 修复 3 — 还款金额校验（防止账务污染）
- **文件**：`services/loan-service/.../loan/repay/RepaymentServiceImpl.java`（L78-L92）
- **改动**：还款前校验 `request.getAmount().compareTo(record.getAmount()) == 0`（不允许部分/超额/0）；过期未还款由调度任务标记 OVERDUE，不走此接口。
- **验收**：非整足额还款返回明确错误且不改状态。

### 修复 4 — 全局统计/管理接口权限
- **文件**：`services/loan-service/.../loan/repay/RepaymentController.java`（L52-L61）；全项目补 `@PreAuthorize`
- **改动**
  - 开启 `@EnableMethodSecurity`；给 `/repayment/statistics`、`/repayment/overdue`（及所有 admin 查询）加 `@PreAuthorize("hasRole('ADMIN')")`。
  - 网关兜底：把统计类路由规整到 `/api/v1/admin/**` 之下。
- **验收**：USER token 访问统计接口返回 403。

### 修复 5 — 内网面收敛（`/internal/**`、`/upload/**`）
- **文件**：`services/common-runtime/.../config/SecurityConfig.java`（L34、L42）、`config/JwtFilter.java`（L127）
- **改动（二选一，推荐 A）**
  - A（网络层）：确认服务仅绑定内网 / 不在公网暴露 `8081–8084`，记录为运维约束。
  - B（应用层）：`/internal/**`、`/upload/**` 改为校验 Feign 内部头（如 `X-Internal-Key`）或仅内网 IP 放行；`/upload` 改为鉴权后才可访问具体文件。
- **验收**：外部请求无法命中未授权内部写接口、无法匿名下载上传材料。

## 第 2 批：账务一致性 + 关键业务正确性

### 修复 6 — 还款计划本金/利息模型统一
- **文件**：`services/loan-service/.../loan/borrow/LoanServiceImpl.java`（L274-L332）、`repay/RepaymentServiceImpl.java`（L84-L92）
- **改动**：`repayment_plan.totalAmount / remainingAmount` 改为按各期【本金+利息】累计维护；结清判断用「已还款期数 == totalPeriods && 金额收齐」，而非 `remaining<=0`；同步调 `loan.status` 与 `user_credit_limit` 回冲。
- **验收**：全流程（借→按期还→结清）金额合计＝本金+总利息，结清状态在最后一期之后才触发。

### 修复 7 — 借款/还款并发保护
- **文件**：`services/loan-service/.../loan/borrow/LoanServiceImpl.java`（L106-L113）、`repay/RepaymentServiceImpl.java`（L84-L92）
- **改动**：扣减/还款用乐观锁（`UserCreditLimit`/`RepaymentPlan` 加 `@Version`）或 `SELECT ... FOR UPDATE`，失败重试/抛重复操作。
- **验收**：并发两次借款/还款不会超额/丢失更新。

### 修复 8 — 决策阈值与状态词汇统一
- **文件**：`services/risk-service/.../risk/assessment/RiskAssessmentServiceImpl.java`（L956-L965、L411-L477）
- **改动**：所有阈值收敛到一处（常量或 enum），消除 580/720 与 642/787 两套；`user.assessment_status` 与 `risk_assessment.status` 取值映射统一（`APPROVED` vs `FINAL_PASS` 二选一）。
- **验收**：同一分数的「分数档提示」与「最终决策」一致。

### 修复 9 — 手工调额负值防线
- **文件**：`services/loan-service/.../loan/limit/UserCreditLimitServiceImpl.java`（L64-L76）
- **改动**：同时校验 `newUsedLimit >= 0` 且 `newTotal >= newUsed`，违反即拒绝。
- **验收**：把 newTotal 调高超过 enough used 时不再出现负数 used。

### 修复 10 — 服务交易内跨服务调用外移
- **文件**：`services/risk-service/.../risk/assessment/RiskAssessmentServiceImpl.java`（L289-L356）、`services/loan-service/.../loan/borrow/LoanServiceImpl.java`（L60-L141）
- **改动**：Feign 调用移出 `@Transactional`（先提交本地事务，再发外部调用；失败走补偿/重试）。
- **验收**：DB 事务不再在线程持有连接期间发起 HTTP。

## 第 3 批：横切质量优化

### 修复 11 — 用户列表 N+1 → 批量
- **文件**：`services/user-service/.../user/admin/AdminUserServiceImpl.java`（L171-L176）
- **改动**：为 `getCreditLimit / getUserLoanSummary / getLatestFinalAssessment` 各加一个「按 userId 集合」的批量内部契约/接口，一次查多用户。
- **验收**：20 用户页由 60 次调用降为 ≤3 次。

### 修复 12 — 登录校验账号状态
- **文件**：`services/user-service/.../user/auth/AuthServiceImpl.java`（L61-L84）
- **改动**：登录后校验 `account_status == ACTIVE`，否则拒绝并提示；把 `System.out.println` 换成 `slf4j` 脱敏日志。
- **验收**：DISABLED 账号无法登录。

### 修复 13 — 调度任务加锁/幂等
- **文件**：`BCardFeatureSnapshotTask`、`CozeBlacklistSyncJob`、`OverdueLimitAdjustTask`、`RepaymentScheduleTask`
- **改动**：引入 ShedLock（`@SchedulerLock`）或 DB 唯一约束/幂等键，防止多实例重复执行。
- **验收**：双实例部署不产生重复快照/重复调整。

### 修复 14 — 异常信息收敛
- **文件**：`services/common-runtime/.../common/GlobalExceptionHandler.java`（L27-L43）
- **改动**：对外只返回友好文案，原始 message/cause 仅写日志。
- **验收**：故意抛错时响应不包含 SQL/路径/堆栈。

### 修复 15 — 补测试
- **重点**：`RepaymentServiceImpl`（归属/金额/并发）、`LoanServiceImpl`（额度扣减/状态）、`RiskAssessmentServiceImpl`（黑名单/收入校验分支）、`RepaymentCalculator`（三种还款方式 + 边界）。
- **验收**：上述核心不法逻辑有回归用例（优先覆盖 Block 相关）。

### 修复 16 — 命名/冗余清理（Nit）
- `DISBURRSED → DISBURSED`（DB 值+枚举同步，需评估存量数据迁移或兼容）。
- 精简 `SecurityUtils.java`（L23-L70）重复方法；移除网关死头 `X-User-Id/X-User-Role`；企业面改用强类型 DTO 替代裸 `Map`。
