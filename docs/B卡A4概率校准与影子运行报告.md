## 2. 概率校准

- 校准集：A3 的 `valid` vintage（未参与模型拟合），OOT 完全留出，不参与任何参数选择。
- 方法：**Platt scaling**，`p_cal = sigmoid(a · logit + b)`，参数 `a=1.01908094`、`b=-1.19058784`。
- 选择说明：校准集内部再切 60/40，Platt 的 Brier=0.1277、Isotonic=0.1241；生产口径**固定 Platt**（单调、参数少、可与 Java 影子侧逐位对齐），Isotonic 仅作诊断，不参与上线参数。
- PDO 映射：`pdo=80 / target_score=650 / target_odds=1 / 分数区间 [350,950]`。

**可靠性曲线（OOT，9 个非空分箱）**

| 分箱 | 样本数 | 平均预测 | 实际坏账率 |
|---|---:|---:|---:|
| 1 | 96 | 0.0494 | 0.0729 |
| 2 | 47 | 0.1367 | 0.1489 |
| 3 | 21 | 0.2509 | 0.1429 |
| 4 | 12 | 0.3542 | 0.3333 |
| 5 | 10 | 0.4369 | 0.3000 |
| 6 | 7 | 0.5414 | 0.7143 |
| 7 | 10 | 0.6396 | 0.5000 |
| 8 | 11 | 0.7560 | 0.5455 |
| 9 | 6 | 0.8421 | 0.6667 |

Spearman = **0.8667**（整体单调向上）；严格单调标记为 false，原因是 OOT 仅 220 条、高分段每箱 6~12 条，统计噪声明显。

**十分位坏账率（OOT，按校准概率从高到低）**

`0.591 → 0.455 → 0.273 → 0.182 → 0.136 → 0.091 → 0.182 → 0.045 → 0.045 → 0.000`

Spearman = **-0.945**；第 7 分位出现一次反弹（n≈22/分位），趋势仍清晰单调。

## 3. 阈值业务模拟

成本假设（可在脚本的 `DEFAULT_COSTS` 中调整）：

| 参数 | 取值 | 含义 |
|---|---|---|
| `lgd` | 0.65 | 违约损失率 |
| `revenue_margin_rate` | 0.08 | 额度压降导致的收入损失比例 |
| `experience_cost_per_contract` | 30 元 | 每次降额的客户体验成本 |
| `review_capacity` | 10% | 人工审核容量上限 |

决策档位：`p < approve_below → 1.0`；`approve_below ≤ p < reject_above → 0.5`；`p ≥ reject_above → 0.0（人工复核）`。

**搜索方式**：在概率网格 `0.000~0.900`（步长 0.005）上穷举，最小化「坏账损失 + 额度收入损失 + 客户体验成本」，并强制审核率 ≤ 容量。**没有使用分位数。**

**选定阈值**：`approve_below=0.055`，`reject_above=0.645`

| 方案 | 审核率 | 坏账成本 | 收入损失 | 体验成本 | 总成本 |
|---|---:|---:|---:|---:|---:|
| **成本最优（模型）** | **9.55%** | 85,528 | 63,113 | 2,670 | **151,311** |
| 旧分位数策略 | 35.0% | 54,857 | 70,922 | 2,970 | 128,749（**超容量，不可用**） |
| 旧分位数策略（同容量 10%） | 10.0% | — | — | — | **160,045** |

→ 同容量下模型阈值比旧策略节省 **8,734 元（约 5.5%）**。

成本更低的候选（116k~117k）审核率高达 68%~71%，已被容量约束剔除。

## 4. 影子运行

**在线实现（Java）**

- `BCardShadowScoreService`：只读 `user_credit_limit`（取 B 分）与最新 `BF_V2.2` 快照，计算线性分 → Platt 概率 → PDO 分 → 阈值档位；与现有策略 `BehaviorScoreService.resolveLimitMultiplier` 对比。
- `BCardShadowDecisionRecorder` + `b_card_shadow_decision` 表（唯一键 `user_id + as_of_date + model_version`）。
- `BCardShadowScoreTask`：`@ConditionalOnProperty(risk.b-card.shadow.enabled=true)`，默认**不注册**；cron 默认 04:10。
- **结构上不可能写额度**：服务不依赖 `LimitAdjustLogMapper`，对 `UserCreditLimitMapper` 只有 `selectList`，无 update/insert/delete。

**离线影子回放（OOT，220 条）**

| 指标 | 值 |
|---|---|
| 决策差异率 | **41.8%** |
| 同容量样本数（10%） | 22 |
| 模型 top-k 坏账率 | 0.5909 |
| 当前策略 top-k 坏账率 | 0.5909 |
| 同容量成本改善 | **+8,733.75** |

**重要限制（必须如实说明）**：概率校准是**单调变换**，不改变排序，因此「同容量 top-k 的坏账率」与原始打分必然相同。要证明「模型分组坏账率明显优于当前线上规则」，必须用**真实数据中的 V1 B 分**作为对照；当前 fixture 没有 B 分，这一条**无法在此环境确认**。

## 8. 剩余风险

1. **真实影子验收缺失**：必须等 `BF_V2.2` 快照积累 + 标签成熟（最早 2027-04），并在影子表中对比真实 V1 B 分。
2. **样本量小**：校准与分箱单调性在 220 条 OOT 上只能看趋势，正式结论需 ≥ 数千条成熟样本。
3. **成本参数是假设值**（LGD 0.65、收入 8%、体验 30 元、容量 10%），必须由风控/业务确认后再固化。
4. **影子任务默认关闭**：需要在真实数据就绪后显式配置 `risk.b-card.shadow.enabled=true` 与 `model-path`。
5. **Platt 是全局校准**：若不同 vintage 的分数分布差异较大，后续可考虑分群校准或按 vintage 监控。
6. **影子表无自动清理**：长期运行需要归档策略（A5 范围）。
