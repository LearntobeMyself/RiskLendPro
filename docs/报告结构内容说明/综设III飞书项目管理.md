# 综设 III 飞书项目管理（导入说明书）

**干活以 [综设III四阶段计划.md](./综设III四阶段计划.md) 为准。** 每人每阶段只交一个能点的结果。旧的 `G-W2-01` 共约 100 条周任务 **作废**，飞书「周任务」只保留 20 行（`G-S1` … `A-S4`）。

组员怎么填： [综设III飞书填写手册.md](./综设III飞书填写手册.md)，粘进飞书文档「使用说明与组约定」。本文负责表结构和导入数据。

覆盖任务书全部必做：七项扩展、微服务、Android、Vue、不少于两种测试、九份文档、部署、A 卡 AUC、爬虫保留、约 10 分钟演示。不含 Kubernetes、消息队列、自研大模型、真实支付。

课件补充要求（角色、三色模块图、细粒度需求、会议纪要）见：

- [综设III四阶段计划.md](./综设III四阶段计划.md)
- [综设III角色与功能模块图.md](./综设III角色与功能模块图.md)
- [综设III需求清单.md](./综设III需求清单.md)

新建行默认状态为 **未开始**。日期按课表自行填入「计划开始 / 计划结束」。

## 1. 飞书怎么建（约 20 分钟）

1. 工作台 → 云空间 → 新建文件夹，名称：`综设III-RiskLendPro项目管理`。
2. 文件夹内新建 **多维表格**，名称：`综设III任务看板`。将默认数据表改名为 **周任务**。
3. 在同一多维表格中再新增数据表：**功能责任**、**接口归属**、**文档交付**、**需求列表**、**会议纪要**。
4. 同一文件夹再建 **飞书文档**，名称：`使用说明与组约定`，把本文第 2 节、第 8 节对账规则，以及会议纪要字段说明粘进去。
5. 文件夹分享给耿、刘、陈、徐、曹（可编辑）；另生成 **只读链接** 发给老师。
6. 多维表格 → 自动化（可选）：状态改为「进行中」时通知负责人；每周日 20:00 提醒当前阶段仍为「未开始 / 进行中」的行。

### 1.1 权限

| 对象 | 权限 |
|------|------|
| 耿、刘、陈、徐、曹 | 文件夹可编辑，可改状态、贴证据链接 |
| 老师 | 只读链接，不可改任务 |
| 目录所有权 | 除公共 DTO 外，禁止改他人 `services/*` 业务代码；要改则提需求由主人合并 |

### 1.2 周任务建议视图

建完字段后立刻建下列视图（老师主要看前三个）：

| 视图名 | 类型 | 设置 |
|--------|------|------|
| 老师总览 | 表格 | 分组 = 阶段编号 |
| 未完成 | 表格 | 筛选：状态 ≠ 已完成 |
| 按人看板 | 看板 | 分组 = 负责人，列 = 状态 |
| 当前阶段 | 表格 | 筛阶段编号 = S1（进入 S2 后改筛选） |
| 耿的任务 / 刘的任务 / 陈的任务 / 徐的任务 / 曹的任务 | 表格 | 各筛对应负责人 |

需求列表建议视图：按所属阶段分组、按角色分组、按模块分组、未验收。

会议纪要建议视图：按时间倒序；老师可读。

## 2. 人员与原则

| 人员 | 主责 | 不做什么 |
|------|------|----------|
| 耿 | `gateway`、`user-service`、`risk-service`、Python 训练、Compose / JMeter 统稿、需求与概要统稿 | 不写产品表、催收案件、大模型对话 |
| 刘 | `loan-service`（消费贷、借款还款、贷中、催收）及对应文档 / 测试 | 不写评分公式、网关、客服 |
| 陈 | `cs-service`（大模型对话、工单）及对应文档 / 测试 | 不写借款表、不改网关业务（只提交路由表） |
| 徐 | 外仓 Vue 管理端，只打网关 | 不做后端；无接口时做假页面不算扩展完成 |
| 曹 | 外仓 Android 借款端，只打网关 | 同上 |

原则：一人守一个可独立启动的服务；前端没有对应后端接口，该扩展不算完成；接口变更必须改「接口归属」并 @徐 @曹。
